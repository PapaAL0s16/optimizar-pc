#   PUP        = optimizador falso / adware / basura. Proponer desinstalar.
#   AV_TERCERO = antivirus de tercero. Quitar SOLO si está vencido, duplicado, o el dueño no lo paga.

#   SE_QUEDA   = drivers y software base. No se toca nunca; solo se lista para que no estorbe.
# Las líneas que empiezan con # se ignoran. La primera coincidencia gana, en este orden.
